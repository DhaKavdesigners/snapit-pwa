# ⚡ Snapit Rider - Next.js PWA Web App

A quick-commerce rider delivery application built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, engineered from Google Stitch UI/UX design project `17501873840527147372`.

---

## 🌟 Features

- **Live Rider Cockpit Dashboard (`/`)**: Dynamic vector map with demand heatmaps, rider GPS beacon, real-time incoming delivery alerts with countdowns, and quick stats Bento grid.
- **My Orders (`/orders`)**: Active delivery management, pickup/dropoff route timeline, 3D turn-by-turn navigation simulator, and touch/mouse **Slide to Arrive** track.
- **Delivery Confirmation (`/confirm-delivery`)**: 4-digit auto-advancing OTP verification input with auto-paste, call customer trigger, and celebration confetti success modal.
- **Earnings & Analytics Hub (`/earnings`)**: Interactive 7-day weekly performance bar chart, daily targets, fare breakdowns, and instant UPI cashout flow with receipts.
- **Rider Onboarding Flow (`/onboarding`)**: Splash screen, Google sign-in, profile & document uploaders (Aadhaar, Driving License, Selfie), zone selection, and live radar verification status tracker.
- **Live Surge Alerts (`/alerts`) & Profile (`/profile`)**: Demand bonus notifications, customer tips, vehicle registration, and preference toggles.

---

## 🚀 Getting Started

### 1. Install dependencies (already completed)
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```

### 3. Open in Browser
Navigate to [http://localhost:3000](http://localhost:3000).
